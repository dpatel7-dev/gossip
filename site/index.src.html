Chat with your friends, right in the terminal.

gossip is a small chat app for direct messages and group servers. Only the people in a chat can read it, and it runs on Mac, Windows and Linux.

$ curl -fsSL https://raw.githubusercontent.com/dpatel7-dev/gossip/main/install.sh | sh

Paste it into Terminal and press Enter. Then open a new window and type gossip.

From nothing to chatting in a minute

You don't need an account anywhere else, and there's nothing to sign up for.

  1. Paste the install lineIt's at the top of this page. It sets everything up, including Node.js if your computer doesn't have it.
  2. Type gossipOpen a new terminal window first, so it knows the new command.
  3. Pick a usernameYour secret keys are made on your computer and never leave it.
  4. Add a friendPress Tab for the menu, choose "Add a person", and say hi.

Questions people ask Pebble

Pebble is the penguin. Pebble answers honestly, including the parts that are less impressive.

Do I have to learn commands?
Pebble

No. Your chats are in a list on the left, and the arrow keys or the mouse move between them. Tab opens a menu for everything else: adding people, servers, colours.

If you like commands they still work, like gossip squawk maya hi.

Can anyone else read my messages?
Pebble

Only the people in the chat. Messages are locked on your computer and unlocked on theirs, the same idea as iMessage. The computer passing them along can see who is talking to whom and when, but never what is said.

What if there's no internet?
Pebble

Run gossip nearby. It finds other people on the same Wi-Fi router or network cable, even if the router isn't online. The computers do still need to be connected to each other somehow.

Can I make a group?
Pebble

Yes, they're called servers. Make one open to everyone or invite-only. Whoever owns a server can remove people from it.

Do I have to update it?
Pebble

It checks for a new version by itself and switches over the next time you start it. You can turn that off with gossip config update off.

Prefer typing? It's all still there.

Every menu item has a command, and they work from any terminal without opening the chat.

gossip
Open the chat.
gossip check
See what you missed.
gossip listen
Stay tuned and print messages as they arrive.
gossip squawk maya hey!
Send a message without opening anything.
gossip nearby
Chat with people on the same Wi-Fi or cable, no internet needed.
gossip config
Change the colours, the penguin, the layout and more.
